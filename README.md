### Cách chạy ở máy mình

1. Tải cả folder này về
2. Mở file `index.html` bằng trình duyệt (Chrome / Cốc Cốc)
3. Không cần cài thêm gì.

### Cách up lên GitHub Pages

1. Up toàn bộ file trong folder này lên repo (nhớ up cả `images/`)
2. Vào `Settings > Pages > Deploy from a branch > main > / (root) > Save`
3. Đợi 1-2 phút là có link `https://ten-cua-ban.github.io/meo-hoc-lai/`
